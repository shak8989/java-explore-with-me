# java-explore-with-me
Template repository for ExploreWithMe project.

## Дополнительная функциональность

Выбранная функциональность: комментарии к событиям.

Планируемые возможности:
- Пользователи могут оставлять комментарии к событиям.
- Администратор может модерировать комментарии.

Реализация запланирована на третий этап дипломного проекта


Разработка будет вестись в отдельной Git-ветке.
